# EnvPol_2026_PMID43057449

**Chronic exposure to low-concentration urban PM2.5 promotes maladaptive kidney repair after ischemic injury via mitochondrial dysfunction and lysosomal stress. **
Sun P, Parra AC, Sanches TR, Wikuats CFH, Butter L, Claessen N, Baelde HJ, Schimmel IM, van der Wel N, Berlingerio SP, Janssens GE, Houtkoope RH, Vaz FM, Roelofs JJTH, Boor P, Strauch M, de Fatima Andrade M, Andrade L, Florquin S, Kers J, Romagnolo A, Tammaro A. 
_Environ Pollut. 2026 Nov 19:129547. doi: 10.1016/j.envpol.2026.129547. Epub ahead of print. PMID: 43057449._

## Data Availability

Raw RNA-seq data are available in the NCBI Gene Expression Omnibus (GEO) under accession number GSE319410.
Raw lipidomics and metabolomics data are available in MetaboLights under accession number MTBLS15842.

## Input Data

The `data/input/` directory contains the processed data matrices and sample metadata used as input for the analysis scripts. These files allow the downstream analyses and figures to be reproduced without reprocessing the raw experimental data.

## RNAseq Analysis Scripts

The `analysis/` directory contains scripts for RNA-seq data processing, statistical analysis, Gene Ontology (GO) enrichment analysis, and Gene Set Enrichment Analysis (GSEA).

## Figure Generation

The `figures/` directory contains scripts used to generate the figures presented in the manuscript.
